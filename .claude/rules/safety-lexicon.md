# 위기 감지 사전을 만질 때 (아동 안전 — 가장 조심할 자리)

> 사전 파일·위기 스크리닝을 쓰는 화면을 열 때만 로드된다.
> ⚠️ `/compact` 후 자동 재주입되지 않는다.

## 🔴 이 자리에서 하루에 두 번 뚫렸다 (2026-08-07)

| | 오너가 실제로 말한 문장 | 왜 못 잡았나 |
|---|---|---|
| 1차 | "아빠가 날 죽인다고 얘기했어" | **'가해 위협' 칸 자체가 없었다.** 자해도 아니고 과거형 폭력도 아니라 두 칸 사이로 샜다 |
| 2차 | "엄마가 날 때리려고 해서" | `"날 때린"` 은 넣었는데 `"날 때리려고"` 는 `"날때리려"` 라 안 맞았다 |

**두 번 다 팀장이 만든 테스트는 전부 통과 상태였다.** 오너가 즉흥적으로 말한 문장에서만 드러났다.

## 규칙

1. **테스트 문장을 코드에서 역산하지 않는다.**
   "이 패턴이 있으니 이 문장을 쓰자"가 아니라 **"실제 아이가 뭐라고 말할까"** 에서 출발한다.
   역산하면 "방어가 옳게 도는가"만 검증되고 **"방어가 딛고 선 판정이 옳은가"는 한 번도 검증되지 않는다.**

2. **'있는 항목 검토'가 아니라 '없는 칸 찾기'를 한다.**
   목록을 훑으면 있는 것만 보인다. 분류 축을 먼저 그리고(자해 / 과거 폭력 / 미래 위협 / 방임 / 정서학대 / 성적위험) **빈 칸을 센다.**
   → 현재 방임·정서학대·성적위험은 **탐지 0건**이다. 상세: `고도화/기능별/GD-37_위기감지_근본개선.md`

3. 🔴 **한국어 어미를 손으로 나열하지 말고 조합으로 전개한다.**
   한국어는 어미가 붙으면 **음절 자체가 바뀐다** — `"때리"` 와 `"때린"` 은 컴퓨터에게 다른 글자다.
   ```python
   [f"{대상} {변화형}" for 대상 in TARGETS for 변화형 in VERBS]
   ```
   손으로 적으면 반드시 빠뜨린다 — 실제로 두 번 빠뜨렸다.

4. **미탐이 오탐보다 훨씬 나쁘다.**
   오탐의 대가 = 아이가 위로를 한 번 더 받고 부모에게 신호 1건.
   미탐의 대가 = 학대 신호를 놓친다.
   → **오탐이 보인다고 사전을 좁히지 말 것.** `_verify_lexicon.py` 의 `KNOWN_FALSE_POSITIVES` 에 "고치지 않기로 한 오탐"이 기록돼 있다.

5. **새 레벨을 만들지 말고 기존 반환값을 재사용할 수 있는지 먼저 본다.**
   레벨을 늘리면 `fixed_response`·`is_high` 양쪽에 등록해야 하는데, `is_high` 를 빠뜨리면
   **탐지는 되는데 부모 신호만 조용히 사라진다.** 처리 방식이 같아야 하는 상황이면 값을 합쳐 그 사고 가능성을 없앤다.

6. **서버와 클라이언트 사전은 반드시 함께 고친다.**
   `server/safety_lexicon.py` ↔ `client/src/utils/safetyLexicon.js` — `_verify_lexicon.py` 가 `node` 로 실제 실행해 동일성을 검사한다.

## EXCLUDE(예외 단어) 적용 규칙 — 칸마다 다르다

| 칸 | EXCLUDE | 왜 |
|---|---|---|
| HIGH_VIOLENCE (이미 일어난 일) | **안 봄** | "게임하다가 아빠한테 맞았어"는 진짜 신호 |
| HIGH_THREAT (아직 안 일어난 말) | **봄** (단 `'게임'` 제외) | 놀이·이야기 속 대사일 여지가 크다. 단 **게임은 허구의 표지가 아니라 싸움의 계기**로 등장한다 — "게임 때문에 아빠가 날 죽인다고 했어" |
| HIGH_SELF (자해) | **봄** | 게임·3인칭 죽음 오탐 방지 |
| SOFT | 안 봄 | |

## 위기 발화는 되읽지 않는다 (GD-A3)

STT 결과를 TTS 로 되읽는 경로(`DailyCheckin`)는 **스크리닝을 먼저** 돌리고, 위기면 되읽기 단계를 **통째로 건너뛴다.**
되읽기는 ①아이 말을 원문 그대로 외부(CLOVA)로 보내고 ②화면에 그대로 띄운다. 순서만 바꾸면 ②가 남는다.
무엇보다 **"죽고 싶다고 했구나! 맞아?" 라고 키디가 되묻는 것 자체가 참사**다.

⚠️ 새로 STT 결과를 쓰는 경로를 만들면 **이 방어를 다시 확인할 것.** 현재 5경로 전수 확인 완료(2026-08-07).
