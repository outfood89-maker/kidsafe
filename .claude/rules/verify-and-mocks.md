# 검증 스크립트·테스트를 쓸 때

> 검증 파일·테스트 파일·훅을 열 때만 로드된다.
> ⚠️ `/compact` 후 자동 재주입되지 않는다.

## 🔴 가짜(mock) 주입 3원칙 — 하루에 3번 반복된 사고 (2026-08-05)

검증하려고 끼운 가짜가 **실제 실행 경로에 제대로 꽂혔는지 확인하지 않아** 세 번 틀렸다.

| # | 무엇을 했나 | 방향 | 결과 |
|---|---|---|---|
| 1 | `write_audit` 을 **통째로** 교체 — 내부에서 예외를 삼키도록 설계된 함수였다 | 거짓 실패 | 없는 버그(500)를 만들어 "실패"로 보고 |
| 2 | `load_dotenv` 를 안 막음 — 로컬 `.env` 가 환경변수를 덮음 | 거짓 실패 | 배포 상황 재현 실패 → 7건 오탐 |
| 3 | 가짜를 **정의만 하고 안 끼움** | 🔴 **거짓 통과** | 진짜 YouTube 호출 → **검증 안 된 채 통과** + 쿼터 300유닛 |

> 🔴 **3번이 가장 위험하다 — 통과로 나오니 아무도 다시 안 본다.** 파이썬은 오타 난 이름에도 새 속성을 조용히 만들어준다.

**3원칙** (도구: `server/_verify_fakes.py` — 매번 새로 짜지 말고 이걸 쓸 것)

1. **경계에 끼운다** — 우리 코드가 외부와 만나는 마지막 지점. 그보다 바깥이면 중간 층(방어막·덮어쓰기)을 건너뛴다.

   | 경계 | 지점 | 도구 |
   |---|---|---|
   | DB | `db.sb_select`·`sb_insert`·`sb_update`·`sb_delete` | `FakeDB` |
   | LLM | `anthropic.AsyncAnthropic` | `FakeAnthropic` |
   | 외부 HTTP | `httpx` (YouTube·CLOVA) | `FakeHTTP` |
   | 환경 | `dotenv.load_dotenv` | `block_dotenv()` · `reload_app()` |

2. **가짜는 호출 기록을 남기고, 테스트가 그 기록을 검사한다.**
   `Recorder.assert_called()` / **`assert_not_called()`** — **0번이어야 하는 것도 반드시 검사**(예: 무토큰 요청의 외부 호출 0). 사고 3은 이 한 줄로 잡혔다.

3. **결과가 이상하면 코드 말고 배선부터 의심한다.**
   - **실패**가 났다 → "버그다" 결론 전에 가짜가 제대로 꽂혔는지
   - **통과**가 났다 → 진짜 검증된 건지. 외부 호출 흔적이 예상과 맞는지

⚠️ `patch()` 는 **없는 이름에 주입하면 즉시 `RuntimeError`** 를 낸다. 오타로 조용히 새는 것을 막는 장치이므로 `setattr` 로 직접 바꾸지 말 것.
🔬 도구가 위 3건을 실제로 잡는지는 `고도화/기능별/GD-S_보안축/verify_fakes_catches.py` 로 재현 검증돼 있다(6/0 통과).

## 검사에 반드시 붙일 것 — 대조군

**"막히는 것만 보면 절반이다."**
"6번째가 막혔다"는 쉽게 확인되지만, **"5번째까지는 안 막힌다"** 를 같이 안 보면
통과 보고를 믿는 사이 **아이가 그림을 못 그린다.**

- 모든 한도·차단 검사에 **대조군**(통과해야 하는 경우)을 붙인다.
- 차단 검사의 진짜 목적은 '막는 것'이 아니라 **'돈이 안 나가는 것'** → 막힌 뒤 외부 호출이 **0번**인지 확인.
- 정탐만 있는 검사는 "전부 잡으면 통과"라 방어를 **넓히는 쪽으로만** 밀린다 → **오탐 케이스를 함께 못박을 것.**

## 🐤 카나리아가 왜 필요한가

윤리선이 뚫려도 **에러가 안 나고 화면은 예쁘게 나온다.** 아무도 신고하지 않는다 — 조용히 배포되고 조용히 신뢰를 깎는다.
그래서 사람이 아니라 **기계가 지킨다.**

방법: 비공유 체크인에 표식을 심고 부모용 API 3종을 호출해 **응답 어디에도 없어야** 통과.
대조군(공유 답변)이 도달하는지도 함께 확인 — 그것마저 없으면 "유출이 없는" 게 아니라 **검사가 아무것도 안 한 것**이다.
⚠️ 실증: `reports.py:397` 의 `share_with_parent` 필터 한 줄을 지우자 **즉시 차단**됐다(2026-08-05).

## 차단 시험 — 방어를 만들었으면 부숴볼 것

방어 코드를 넣었으면 **일부러 제거하고 검사가 잡는지** 확인한다. 안 잡히면 그 검사는 아무것도 안 하는 것이다.
선례: 한도 검사 제거(22건) · 소유권 검사 제거(6건) · 한도 검사를 `try` 안으로(16건) · 위협 패턴 제거(12건) · 사전 한쪽만 수정(갈라진 항목 출력)

## 🔴 다른 언어의 소스를 정규식으로 긁어 비교하지 말 것 (2026-08-07)

JS 사전을 정규식으로 파싱하던 검사는 패턴이 `flatMap` 조합 생성으로 바뀌자 **빈 배열을 읽고 조용히 통과**할 뻔했다.
→ `node` 로 **실제 실행해 결과를 비교**한다. 그리고 **"목록이 N개 이상인가"를 따로 검사** — 양쪽 다 비어도 '동일'은 통과하기 때문이다.

## 새 검사를 만들면 등록할 것

등록하지 않으면 **아무도 실행하지 않는 파일**이 된다.
