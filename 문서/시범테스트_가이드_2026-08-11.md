## 🧭 순서 — 이대로 하면 사전작업이 없다

```
A 체크인 (한 아이, 끝까지)  →  그대로 그림일기 한 편 쓰기
        ↓ 그 일기가 아래 둘의 재료가 된다
C 저장 용량 카드 (목록에 그 일기가 뜬다)
        ↓
D 프로필 삭제 (그 아이) → 파일이 정말 지워졌는지 SQL 로
```

🔴 **A 를 건너뛰고 C·D 만 하면** 목록이 비어 있어 *"되는지 안 되는지"* 를 못 가린다.
그래서 A 가 첫 번째다 — 제일 중요하기도 하고, **나머지의 준비물이기도 하다.**

| | 사전작업 | 되돌릴 수 있나 |
|---|---|---|
| **A** 체크인 | 없음 | 예 |
| **C** 용량 카드 | A 의 결과물 | 보기만 함 |
| **D** 프로필 삭제 | A 의 결과물 | 🔴 **아니오 — 테스트용 아이로만** |
| **E** 탈퇴 | 계정 하나 | 🔴 **아니오 — 버리는 계정으로만** |

## 🔴 A. 체크인 — **제일 중요하다**

**왜:** 오늘 여기 한도를 **처음으로 실제로 걸었다.**
어제까지는 아무도 안 부르는 문에 걸려 있어서 **한 번도 발동한 적이 없었다.**
오늘 진짜 경로에 옮겨 달았고, 그 과정에서 값이 너무 좁은 것도 발견해 넓혔다(8 → 40).

**할 일**
1. 아이 화면 → 체크인을 **처음부터 끝까지** 한 번
2. 확인:
   - 키디 첫 인사가 나오는가 *(안 나와도 로컬 인사말로 대체된다 — 그건 정상)*
   - 질문 3개(기분 · 하루 · 볼 것)에 **각각 키디 반응**이 뜨는가
   - 반응이 **한 글자씩 흘러나오는가**(스트리밍)

**🔴 실패 신호 — 보이면 즉시 알려달라**
- 반응 자리에 *"키디가 생각 중이야! 잠깐만 기다려줄래?"* 나 *"오늘 키디가 이야기를 많이 들었어"* 가 뜬다
  → **한도에 걸린 것.** 첫 세션에서 이게 뜨면 값이 아직 좁다는 뜻이다
- 반응이 아예 안 나오고 넘어간다 → 조용히 막힌 것

**아이가 여럿이면:** 아이를 바꿔가며 **3명까지** 해볼 것. (오늘 고친 게 정확히 그 지점이다)

## 📦 C. 저장 용량 카드

**왜:** 오늘 새로 만든 화면이다. 아직 아무도 눈으로 본 적이 없다.

> 💡 **사전작업 필요 없다.** 카드가 뜨는 조건은 `DIARY_SERVER` 뿐이라
> (`ParentDashboard.jsx:1204`) **일기가 0편이어도, 프로필이 0개여도 뜬다.**
> 다만 🧹 정리 목록에 **항목이 보이려면** 서버에 올라간 일기가 한 편 필요하다 —
> 🔴 **그건 A 에서 자연히 생긴다.** A → C 순서로만 하면 따로 준비할 게 없다.

**할 일**
부모 대시보드 → **가족 책장** 탭

**통과 — 이 순서로 보인다**
1. '어디서나 열리는 가족 책장' 동의 카드
2. 🆕 그 **바로 아래** 📦 **그림일기 저장 공간** 카드
   - 초록 막대 + `0 / 1.00GB` 같은 숫자
   - *"여유가 있어요. 80% 를 넘으면 여기서 알려드릴게요."*
   - 버튼 둘: 🧹 **오래된 것부터 정리** · 📚 **가족 책장에서 보고 고르기**
3. 🧹 를 누르면 → 목록이 열린다 (일기가 없으면 *"정리할 일기가 아직 없어요"*)
4. 📚 를 누르면 → **가족 책장으로 이동**한다 *(페이지가 새로 뜨는 게 아니라 부드럽게 넘어가야 한다)*

**🔴 실패:** 카드가 아예 안 보인다 / *"사용량을 읽지 못했어요"* 가 뜬다

## 🗑 D. 아이 프로필 삭제 — **개인정보**

**왜:** 오늘 고친 것 중 제일 무거운 건이다.
그전까지는 **아이 프로필을 지워도 그 아이의 그림·목소리 파일이 서버에 영원히 남았다.**
(DB 기록은 지워졌는데 파일만 남는 구조였다)

**어디서:** 부모 대시보드 → **👶 자녀 설정** 탭 (좌측 메뉴)

**할 일 — 테스트용 아이로만 할 것 (되돌릴 수 없다)**
1. 그 아이로 그림일기를 **한 편 저장** (A 에서 이미 했으면 건너뛴다)
2. **삭제 전**에 한 번 재본다:
   ```bash
   cd server && ./venv/bin/python check_leftovers.py
   ```
3. 👶 자녀 설정 탭 → 그 프로필 **삭제**
4. **삭제 후** 같은 명령을 한 번 더

**통과:** 그림·음성 개수가 **줄어 있고**, `안 치운 파일 없음` 이 뜬다
**🔴 실패:** `🔴 안 치운 파일 N개` 가 뜬다 → 파일이 서버에 남아 있다는 뜻. 알려달라

> ⚠️ **왜 명령을 쳐야 하나 — 화면이 안 알려준다.**
> 서버는 `{"files": {"removedNow": N, "queued": N}}` 을 돌려주는데
> 화면이 그 값을 **버린다**(`ParentDashboard.jsx:528` — `await deleteProfile(profileId);`).
> 파일이 하나도 안 지워져도 화면은 똑같이 조용하다.
> 🔴 이건 **고칠 자리로 남아 있다**(미해결 질문 30). 지금은 명령으로 대신 본다.
>
> 💡 명령을 치기 싫으면 **나에게 "남은 것 확인해줘"** 라고만 해도 된다. 대신 돌려주겠다.
