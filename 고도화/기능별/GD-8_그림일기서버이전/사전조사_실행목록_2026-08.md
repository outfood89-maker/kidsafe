### C3 상세 — 확정: 고지 (2026-08-05)

**고지할 사실 (공식 문서 확인 완료):**
- 아이가 그린 그림 원본과 일기 문장이 **'이어그리기' 시 미국 OpenAI로 전송**된다.
- **기본값으로 최대 30일 보관된다.** OpenAI 원문: *"abuse monitoring logs are generated for all API feature usage and retained for up to 30 days"* / *"Abuse monitoring logs may contain certain **customer content, such as prompts and responses**"* → **메타데이터만이 아니라 보낸 내용(그림·문장) 자체가 포함**된다.
- 30일 뒤 자동 삭제. 광고·학습에는 사용되지 않음.

**왜 회피가 아니라 고지인가:**
- Zero Data Retention(보관 안 함)은 **엔터프라이즈 계약 고객 한정** — 공식 문서 명시. 소규모 API 계정은 신청 불가.
- 한국 리전도 이미지에는 ZDR 또는 강화 모니터링 승인이 전제 → 같은 벽.
- ⚠️ 그래도 **OpenAI 문의는 남겨둔다** — 문서가 최신이 아닐 수 있고 스타트업 프로그램 가능성. 단 **기대치는 낮게.**

**고지 문안 방향 (긍정 프레임):** *"아이 그림은 AI가 이어 그리기 위해 최대 30일간만 처리된 뒤 자동 삭제되며, 광고나 AI 학습에 사용되지 않습니다."*
