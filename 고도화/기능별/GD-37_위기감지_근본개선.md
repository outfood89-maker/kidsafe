# [고도화 GD-37] 위기 감지 근본 개선 — '단어 목록'에서 '뜻을 읽는 것'으로

*작성 2026-08-07(팀장) · 발단: 오너 문제제기 「가짓수가 너무 많고 구멍이 뚫려있는 느낌」*

## §1. 오너가 짚은 것

> *"이거 근데 너무 가짓수가 많고 구멍이 뚫려있는 느낌이거든?"*

정확한 진단이다. 그리고 **느낌이 아니라 사실**이다. 같은 날 **두 번 연속** 뚫렸다.

| | 오너가 말한 문장 | 결과 |
|---|---|---|
| 1차 | "아빠가 날 죽인다고 얘기했어" | 미탐 → '가해 위협' 칸 자체가 없었음 |
| 2차 | "엄마가 날 때리려고 해서" | 미탐 → `"날 때린"`은 있는데 `"날 때리려고"`가 없었음 |

두 번 다 **팀장이 만든 테스트는 전부 통과한 상태**였다. 오너가 즉흥적으로 말한 문장에서만 드러났다.

---

## §2. 지금 방식이 무엇인가 — 한 문단으로

**금지어 목록을 놓고 아이 말에 그 글자가 들어있나 찾는다.** 그게 전부다.

```
"죽고 싶", "날 때리", "한테 맞았" … 이런 문자열 68개를 늘어놓고
아이 말에서 공백을 지운 뒤, 그 안에 이 글자가 있는지 본다.
```

빠르고(0.001초), 공짜고, 100% 예측 가능하다. **인터넷이 끊겨도 돈다.** 좋은 성질이다.
문제는 이 방식이 **뜻을 전혀 모른다**는 것이다. 글자만 본다.

---

## §3. 왜 계속 뚫리는가 — 원리적 한계 3가지

### 3-1. 한국어는 어미가 붙으면 글자가 바뀐다

컴퓨터가 보기에 이건 전부 **다른 단어**다:

> 때리려고 · 때린다 · 때릴거야 · 때려서 · 때렸어 · 때리겠대 · 때린대 · 때릴래

사람은 "때리-"가 공통이라고 보지만, `"때리"`와 `"때린"`은 글자가 다르다. **어간만으로는 못 집는다.**
2026-08-07에 조합 전개(대상 3 × 변화형 13 = 39개)로 이 구멍을 크게 줄였지만, **어미의 가짓수는 원리상 끝이 없다.**

### 3-2. 문맥을 못 본다 — 지금은 '단어 하나'로 때우고 있다

| 문장 | 사람의 판단 | 지금 방식 |
|---|---|---|
| "게임에서 좀비가 날 죽인대" | 놀이 이야기 | `"좀비"`가 있으니 넘어감 |
| "게임 때문에 아빠가 날 죽인대" | 🔴 진짜 위협 | `"게임"`을 예외에서 빼서 겨우 잡음 |

**두 문장의 차이는 '게임'이 어디에 붙었나'인데, 지금 방식은 그걸 볼 수 없다.**
그래서 "게임은 예외 단어에서 빼자" 같은 **땜질**로 맞춘 상태다. 다음번엔 다른 단어에서 같은 문제가 난다.

### 3-3. 칸에 없는 학대 유형은 아예 안 보인다

목록을 아무리 늘려도, **분류 자체가 없는 것**은 찾을 수 없다. 지금 있는 칸은 3개뿐이다.

## §4. 지금 못 잡는 것들 — 실측 (2026-08-07)

### 🔴 4-1. 칸 자체가 없는 학대 유형

| 유형 | 아이가 할 법한 말 | 결과 |
|---|---|---|
| **방임** | "엄마가 밥을 안 줘" · "며칠째 혼자 있었어" · "아무도 안 데리러 와" · "배고픈데 집에 먹을게 없어" | **5/5 미탐** |
| **정서 학대** | "엄마가 맨날 나보고 바보래" · "너 같은 건 필요없대" · "넌 왜 태어났냐고 했어" | **4/4 미탐** |
| **성적 위험** | (문장 예시는 전문가 자문 후 작성) | 칸 없음 |

> ⚠️ **방임은 아동학대 신고 유형 중 비중이 크다.** 그런데 우리 사전에는 단어 하나도 없다.

### 🔴 4-2. 간접·완곡 표현 — 아이는 원래 이렇게 말한다

| 아이 말 | 실제 의미 | 결과 |
|---|---|---|
| "아빠 술 마시면 무서워" | 반복적 공포 상황 | **미탐** |
| "엄마 오는 소리 나면 숨어" | 회피 행동 — 강한 신호 | **미탐** |
| "아빠가 화나면 너무 무서워" | 반복 노출 | **미탐** |
| "집에 가기 싫어" | 가정 내 문제 가능성 | **미탐** |

**어린아이일수록 "때렸어" 같은 직접 표현을 안 쓴다.** 우리 사전은 직접 표현만 본다.

### 🟠 4-3. 표기 흔들림 — 특히 **음성 인식**에서 잦다

| 입력 | 결과 | 비고 |
|---|---|---|
| "죽 고 싶 어" | ✅ 잡힘 | 공백 제거 방어가 작동 |
| "때리려구했어" | **미탐** | 구어체 발음 — STT가 이렇게 받아쓴다 |
| "날 쥭인대" | **미탐** | 오타·발음 |
| "ㅈㄱㅅㅇ" | **미탐** | 초성 (연령대상 낮아 실사용 가능성은 낮음) |

**아이가 마이크로 말하면 STT가 구어체 그대로 받아쓴다.** 이 칸은 실사용에서 계속 부딪힐 자리다.

### 🟠 4-4. 피해자가 '내'가 아닐 때 — 일관성이 없다

| 문장 | 결과 | 왜 |
|---|---|---|
| "엄마가 동생을 때렸어" | 🔴 잡힘 | `"때렸어"`에 **우연히** 걸림 |
| "아빠가 엄마를 때린다고 했어" | **미탐** | 대상이 '나'가 아니라 안 걸림 |

**가정폭력 목격도 아동학대**다. 그런데 지금은 잡히기도 하고 안 잡히기도 한다 — **일관성이 없다는 게 가장 나쁘다.**

## §5. 어떻게 고칠 수 있나 — 선택지 4개

### A. 지금 방식 유지 + 계속 패턴 추가

| | |
|---|---|
| 비용 | 0원 · 작업 1~2시간/회 |
| 장점 | 빠르고 확실하고 오프라인 동작. 지금까지 해온 방식 |
| 단점 | 🔴 **뚫릴 때마다 사후에 막는다.** 아이가 실제로 새는 말을 해야 알 수 있다 |
| 판정 | **버릴 수는 없다** — 1차 방어로는 여전히 최선. 다만 **이것만으로는 부족하다** |

### B. 형태소 분석기 도입 (어간 추출)

"때리려고 / 때린다 / 때릴거야"를 전부 `때리-`로 환원해 어미 문제를 원천 해결한다.

| | |
|---|---|
| 비용 | 0원(오픈소스) · 작업 1~2일 |
| 장점 | §3-1(어미) 완전 해결. 여전히 빠르고 오프라인 |
| 단점 | 🔴 **§3-2(문맥)·§4-1(없는 칸)은 그대로.** 브라우저에서 돌릴 한국어 분석기는 무겁고 선택지가 적다 |
| 판정 | 어미 문제만 푼다. **가장 큰 구멍(문맥·없는 칸)은 남는다** |

### C. LLM 2차 판정 병행 ⭐

사전이 1차로 거르고, **사전이 못 잡은 말만** Haiku에게 "이 아이 말에 어른의 도움이 필요한 신호가 있나?"를 묻는다.

| | |
|---|---|
| 비용 | **1회 약 0.35원** (Haiku, 입력 ~200토큰) — 하루 20회면 **7원** |
| 장점 | 🟢 문맥을 읽는다 · 🟢 **칸에 없는 유형도 잡는다**(방임·정서학대·간접표현 전부) · 🟢 새 유형마다 코드 수정 불필요 |
| 단점 | ⚠️ 느리다(0.5~1초) · ⚠️ API 장애 시 2차 방어 소실 · ⚠️ **아이 말이 한 번 더 외부로 나간다** · ⚠️ 판정이 100% 일정하지 않다 |
| 판정 | **가장 큰 효과.** 단 사전을 대체하는 게 아니라 **덧대는** 것이어야 한다 |

### D. 하이브리드 — C + 사전 유지 ⭐⭐ **팀장 권고**

```
아이 말
  ├─ 1차: 사전 (0.001초, 공짜, 오프라인, 100% 확실)
  │        → 잡히면 즉시 고정 응답 + 부모 신호. LLM 안 부름.
  └─ 2차: 사전이 못 잡았고 서버 경로일 때만 → Haiku 판정
           → 위험 판정이면 같은 고정 응답 + 부모 신호
```

**왜 이 구조인가**
- 🟢 **사전이 잡는 건 지금처럼 즉시·공짜·확실하게** 처리된다(속도 손해 0, 비용 0)
- 🟢 LLM이 죽어도 **1차 방어는 그대로** 산다 — 안전 기능이 외부 서비스에 인질로 잡히지 않는다
- 🟢 §4의 미탐 대부분(방임·정서학대·간접표현·표기흔들림)을 **한 번에** 덮는다
- 🟢 비용은 "사전이 못 잡은 것"에만 드니 대부분의 평범한 답변은 **0원**

**⚠️ 그래도 남는 문제 (착수 전 반드시 결정)**
1. **프론트 단독 경로는 LLM을 못 쓴다.** `DiaryFlow`·`DailyCheckin`의 일부 스크리닝은 서버를 안 거친다(설계상 의도). 이 경로는 사전만 남는다 → 2차 방어가 없는 구간이 생긴다.
2. **아이 말이 한 번 더 외부(Anthropic)로 나간다.** 처리방침(B1) 고지 대상이며, 「비밀이야」 정책([C1 결정](GD-8_그림일기서버이전/사전조사_실행목록_2026-08.md))과 정면으로 맞물린다.
3. **오탐 처리.** LLM이 "위험"이라고 하면 부모에게 신호가 간다. 늑대소년이 되면 진짜 신호를 죽인다 → **LLM 판정은 신호 강도를 낮춰서(soft) 시작**하는 안을 검토할 것.

## §6. 팀장 권고 — 순서

| 순 | 무엇 | 왜 이 순서인가 |
|---|---|---|
| 1 | **없는 칸 채우기 (방임·정서학대·성적위험)** | 🔴 지금 **0건 탐지**다. 방식을 안 바꿔도 당장 효과가 가장 크다. 다만 **아동학대 분류 체계 조사 + 전문가 자문**이 먼저다 |
| 2 | **D(하이브리드) 도입** | 위 1을 해도 간접표현·문맥은 못 잡는다. 근본 해결은 여기서 나온다 |
| 3 | B(형태소 분석) | D가 들어오면 어미 문제의 중요도가 크게 떨어진다. **D 이후에 필요성을 재평가** |

> ⚠️ **1번은 사전 작업이 아니라 조사 작업이다.** 아동학대 유형 분류(신체·정서·성·방임)와 각 유형에서 아이가 실제로 하는 말을 확보해야 한다. 문장을 상상해서 넣으면 **또 같은 실수**다 — 2026-08-07에 두 번 그랬다.

## §7. 착수 조건 / 결정 대기

| # | 결정할 것 | 왜 |
|---|---|---|
| 1 | 아이 말을 위기 판정 목적으로 **한 번 더 LLM에 보낼 것인가** | 처리방침(B1)·「비밀이야」 정책과 직결. **오너 결정 사항** |
| 2 | LLM 판정 결과의 **신호 강도** (부모 알림 O/X) | 늑대소년 방지 vs 미탐 방지의 균형 |

| 4 | 아동학대 분류 조사에 **전문가 자문을 붙일 것인가** | 지금 사전은 개발자가 상상해서 만든 것이다. 실제 사례 기반이 아니다 |
