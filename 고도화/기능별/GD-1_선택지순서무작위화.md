## §0. 전제 (팀장 확정 — 전부 필수)

1. **왜 하는가:** 4~7세는 선택지가 주어지면 *판단*이 아니라 *순응*한다. 특히 **위치 편향**(첫 번째 또는 마지막을 고름)이 강하다. 순서를 고정해두면 아이의 답이 "아이의 마음"이 아니라 "우리가 배치한 순서"를 반영하게 되고, 그 왜곡된 답이 그대로 **그림일기·주간 리포트·AI 코치 해석의 재료**가 된다. 즉 이건 UI 개선이 아니라 **데이터 신뢰도 문제**다.
2. **하루 안에서는 순서가 고정되어야 한다.** 리렌더링마다 순서가 바뀌면 아이가 고르려던 카드가 움직인다(4~7세에게 치명적). → **날짜+프로필 시드 기반 결정적 셔플**. 계보: `client/src/utils/diaryStore.js`의 `getTodayQuestion()`이 이미 `[...`${pid}_${today}`].reduce(...)` 시드 방식을 쓴다. **같은 방식을 재사용할 것**(새 난수 체계 신설 금지).
3. **씨앗(관심사) 우선 배치 의도를 깨지 말 것.** `DailyCheckin.jsx:284-287`의 `buildWatchOptions()`는 **F0 관심사 씨앗을 앞에 놓는 것이 의도된 설계**다. 전체를 뒤섞으면 이 의도가 사라진다. → **블록 분리 셔플**: 씨앗 블록은 앞, 나머지는 뒤로 유지하되 **각 블록 내부에서만 순서를 섞는다.**
4. **기존 동작 보존 (CLAUDE.md 재발방지 규칙 §대규모 리라이트):** 이 작업은 **순서만** 바꾼다. 선택지의 **개수·내용·필터링·저장 형식(`answerType`, 답 문자열)은 일절 변경 금지.** 착수 전 `DailyCheckin.jsx`의 조건부 분기(`current.answerType === "emoji_select" ? ... : ...`, `watchOptions || current.options...`)를 목록화하고 새 코드에 **그대로 보존**할 것.
5. **감정 이모지(`emoji_select`)는 셔플 대상에서 제외.** 😄🙂😐😢😡는 **기분의 스펙트럼 순서** 자체가 의미다(`DailyCheckin.jsx:42` `EMOJI_MOOD`). 섞으면 아이가 읽지 못한다.

## §1. 구현

### 1-1. 셔플 유틸 신설 — `client/src/utils/stableShuffle.js` (신규)

```
export function stableShuffle(arr, seedStr)
```
- 입력 배열을 **복사**해서 반환(원본 불변). 빈 배열·1개 배열은 그대로 반환.
- `seedStr`로 결정적 난수 생성 → Fisher–Yates 셔플. 같은 시드면 항상 같은 결과.
- 시드 문자열 생성 규칙은 `diaryStore.getTodayQuestion()`과 동일 계보로 통일.

### 1-2. 적용 지점 (`client/src/components/DailyCheckin.jsx`)

| 위치 | 현재 | 변경 |
|---|---|---|
| `:812` `emoji_select` 분기 | 이모지 5종 | **변경 없음** (§0-5) |
| `:815` `current.options.map(...)` | 서버 순서 그대로 | `stableShuffle(current.options, seed)` |
| `:829` `watchOptions \|\| current.options...` | 씨앗 우선 + 인기 주제 | **블록 분리 셔플** (§0-3) — `buildWatchOptions()` 안에서 씨앗 블록과 보충 블록을 각각 셔플한 뒤 이어붙인다 |

- **시드:** `` `${profileId}_${checkinDate}_${current.qId}` `` — 프로필·날짜·질문마다 다르고, 같은 날 같은 질문이면 항상 동일.
- 셔플 결과는 **`useMemo`로 고정**해 리렌더링마다 재계산되지 않게 할 것.

### 1-3. 건드리지 말 것
- 서버(`server/routers/checkins.py`) — 무변경. 순서는 **표시 계층에서만** 바꾼다.
- 저장 payload(`qId/qText/answer/answerType`) — 무변경. 답은 **선택한 값**이지 인덱스가 아니므로 셔플과 무관.
- `_mask_private_answers`(비공개 미저장) 등 윤리 로직 — 무접촉.
