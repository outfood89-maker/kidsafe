# GD-41 — 서비스 전체 영문화 (글로벌 판)

작성: 2026-08-22 (오너 발의 — *"키디 사이트를 아예 모든 걸 영문으로 바꾸는 거야"*)
상태: **🔵 3층 — 설계 회의 먼저 (뭘 만들지부터 결정)** · 착수 전 재료 정리

> 🔴 **이것은 번역 작업이 아니다.** 키디의 안전·정서 장치는 전부 **한국어 언어 자산** 위에
> 서 있다. 영문판 = 그 자산을 영어로 **새로 구축**하는 일이며, 특히 위기 감지는
> 번역으로 만들면 GD-37 이 경고한 "상상한 문장만 잡는" 사고를 영어로 반복하게 된다.

---

## 0. 왜 하는가 (후보 — 오너 확정 전)

- 글로벌 확장의 첫 관문 (앱 출시 이후의 시장 확대)
- StoryWeaver 그림책 연동(교육 축)과 시너지 — 원본이 영어권 자료라 영어판이 자연스럽다
- 국내 수요 가능성: 영어 노출 가정·다문화 가정
- KT 글로벌 채널과의 접점 여부는 미확인 (고도화 협의에서 질문 후보)

## 1. 🔴 언어 자산 5종 — 각각 성격이 다르다

| # | 자산 | 지금 상태 | 영문화의 성격 |
|---|---|---|---|
| 1 | UI 문자열 (아이·부모 화면 전체) | 컴포넌트에 한국어 하드코딩 · i18n 구조 없음 | **선행 공사**: 문자열 외부화(react-i18next 류) — 전 화면 리팩토링, 동작 보존 검증 필수 |
| 2 | 서버 메시지 (오류·한도 안내 등) | `HTTPException detail`·`quota.py msg_*` 한국어 하드코딩 | 서버도 언어 키 구조로 — 프론트가 언어를 알려주는 계약 신설 |
| 3 | 키디의 말 (인사·질문·반응·위로) | 사람 검수를 거친 한국어 카피 | 🔴 번역이 아니라 **영어 아동 카피를 새로 검수** — 연령 어휘 수준·문화(스킨십 표현 등)까지. 아동 문구 게이트가 영어에도 그대로 적용 |
| 4 | 🚨 위기 감지 사전 | 한국어 표현 사전 (서버↔클라 동기 검증 장치 있음) | 🔴 **가장 무겁다.** 영어 위기 표현(자해·학대·방임·간접 표현)은 번역 불가 — 영어권 공개 표준(아동보호 기관 자료) 기반으로 새로 구축 + 정탐/오탐 양방향 측정. GD-37 방법론 승계 |
| 5 | 검수 키워드 사전 (Tier0) | 한국어 유해 키워드 | 영어권 유해 콘텐츠 사전 별도 구축 · Tier1~2(AI 판정)는 언어 무관이라 재사용 |

## 2. 언어 자산 밖의 기술 항목

- **TTS**: CLOVA 영어 보이스 지원 여부 확인 필요 — 안 되면 대체 엔진(비용·톤 재검토)
- **STT**: Web Speech `lang` 전환 (기술적으로 쉬움 · 아동 영어 인식률은 별도 확인)
- **콘텐츠**: YouTube 검색어·추천·연령 적합성 축이 영어권 콘텐츠 기준으로 재보정 필요
- **위기 대응 연계**: 안내하는 기관·번호가 국가별로 다름 (112/1391 → 국가별 대응)
- 날짜·시간 표기 · 처리방침(법역이 달라지면 법률 검토 범위도 달라짐 — 🔴 GDPR/COPPA 는 별개 세계)

## 3. 설계 회의에서 정할 것 (착수 조건)

1. **대상 시장** — 해외 진출인가, 국내 영어 사용 가정인가 (콘텐츠·기관 연계가 완전히 달라진다)
2. **형태** — 한/영 토글(한 서비스 2개 언어)인가, 영어판 별도 배포인가
3. **범위 1차선** — UI만 먼저(콘텐츠·위기 감지는 한국어 유지)라는 절충이 성립하는가
   → 🔴 성립 안 한다고 본다: 영어 UI 로 아이를 받으면 위기 감지도 영어여야 한다. **안전이 언어를 따라가야 한다**
4. 법역 — 해외라면 개인정보 규제(GDPR·COPPA)가 한국법과 별개로 붙는다

## 4. 순서 제안 (확정 아님)

```
1단계  문자열 외부화 (i18n 골조 — 화면은 여전히 한국어, 동작 보존 검증)
2단계  UI·안내 번역 + 영어 아동 카피 검수
3단계  언어 자산 재구축 (위기 사전 → 검수 키워드 → 키디의 말 전량)
4단계  콘텐츠·기관 연계 현지화
```

1단계는 영문화와 무관하게도 가치가 있다(문자열 정리 = 카피 관리 일원화) —
**영문화를 안 하기로 해도 버려지지 않는 공사**라 먼저 떼어 착수할 수 있다.
