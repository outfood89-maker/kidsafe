## 0. 한 줄 메시지 (심사 어필의 심장)

> **"키디는 완성된 앱이 아니라, 아이와 함께 자라는 앱이다."**
> 검수(해자 A)는 이미 증명됐다. 고도화는 **관계(정체성 B)를 시간·콘텐츠·수익으로 확장**해, 이 관계가 왜 방어 가능한 해자인지 보여준다. 그 절정은 — **아이가 자라면 키디가 스스로 작별을 고하는 '졸업'.** 재방문을 구걸하지 않는 유일한 아동 앱.

## 3. 핵심 기능 카드 (유실 복구분 + 로드맵)

> ⚠️ 아래 ①②③은 공모전 신청서에 확정 기술됐으나 **코드 구현본이 유실**된 상태(7/12 이후 작업이 git 미커밋 → 맥 이전 중 소실). 설계는 신청서에 온전히 남아있어 **그대로 재구현 가능.** 상세: 부록 B.

### ① ⏰ 목소리 타임캡슐
- **무엇:** 그림일기에 남긴 **아이 목소리 한 토막이 1년 뒤 '작년 오늘'로 부모에게 다시 도착**.
- **왜 강력한가:** 시간 축의 완성. 하루 기록이 1년 뒤 눈물의 순간이 된다. 기존 그림일기 음성 저장 인프라(`diaryAudioStore`) 재활용 → 구현 난이도 낮음.
- **심사 어필:** "기록이 쌓일수록 해지 못 하는 정서 자산"의 가장 극적인 증거.

### ② 🎓 키디 졸업
- **무엇:** 아이가 9~10살, 스스로 마음을 말할 수 있게 되면 **키디가 작별 인사**를 하고 아이를 떠나보낸다. "이제 미디어를 건강하게 즐길 준비가 됐어."
- **왜 강력한가:** 애착 유발·리텐션 구걸을 하는 여느 아동 앱과 **정반대 설계.** "키디의 성공 = 아이가 키디를 덜 필요로 하게 되는 것." 윤리 정체성의 정점.
- **심사 어필:** Q18(AI 의존 우려)의 완벽한 답. 이 한 기능이 제품 철학 전체를 증명한다.

### ③ 📖 가족 앨범 PDF·실물 인쇄 (프리미엄 BM 1순위)
- **무엇:** 아이의 그림일기 + 부모의 편지가 쌓인 **한 달을 한 권의 책으로.** 디지털 PDF → 실물 인쇄·배송.
- **왜 강력한가:** 수익 축의 핵심. 구독을 끊는 순간 추억 앨범이 멈추므로 **정서적 락인.** 원가는 캐싱 구조로 통제.
- **현황:** '앨범 그리드' 화면(월별 한 권)은 이미 구현(diary-v0). 남은 것 = **PDF 생성 + 인쇄 발주 연동.**

### ④ 📚 콘텐츠 확장 — 키디가 읽어주는 첫 그림책 → **§4 별도**

### ⑤ 🛡️ "키디가 걸러낸 영상" 가시성 카드 (로드맵 1순위)
- **무엇:** 부모에게 "이번 주 키디가 미리 보고 걸러낸 영상 12개 — OO이는 만나지 않았어요" + 사유 분포 칩(상업성 5·연령 4·안전 3).
- **원칙(필수):** 숫자·사유 분포만(차단 영상 목록·썸네일 나열 **금지**), **안심 프레임(공포 마케팅 금지)**, 차단/약속준수 로깅 인프라 통합 설계.
- **심사 어필:** "검수가 잘될수록 조용해지는 역설"을 깬다 = 프리미엄 구독의 체감 근거(보안 제품의 "차단한 위협 N건" 논리).

### ⑥ 그 외 백로그 (로드맵)
- **패턴 감지 v2** — 상승추세만 잡는 v1 → 비율+지속 고위험(4→4→4) 규칙
- **키디의 방 v1** — 배경 씬 아트·대화 주제 카드·발음 피드백·수준 선택 UI
- 회전질문 칩 반려동물 개인화, 부모 대시보드 7탭→3그룹 재편, 찜 목록 연령 표시

## 4. 콘텐츠 축 확장 — 오픈 라이선스 그림책 연동 ⭐신규 조사

**전략:** 유튜브를 **대체하지 않고**, 광고 없는 오픈 라이선스 그림책·오디오를 **옆에 얹는다(+α).** 근거: ①안전(오픈 소스는 광고·알고리즘 없음 — 유튜브 임베드는 광고 제거가 정책상 금지) ②차별화(키디가 함께 읽어주는 경험 = 정체성 직결) ③비용(계약·수수료 0).

### 최우선: StoryWeaver (Pratham Books)
- **라이선스: CC-BY 4.0 → 상업 이용 명시적 허용.** 앱에 넣어 서비스 OK. 계약·수수료 없음.
- **한국어 그림책 989권 실재** (레벨 1~4 → 4~7세 타깃 매칭 쉬움). 직접 URL:
  `https://storyweaver.org.in/en/search?language=Korean&languages[]=Korean&query=&sort=Ratings`
- **연동 아이디어:** StoryWeaver 그림책 본문+삽화를 가져오고, **낭독은 키디가 직접**(우리 TTS). "키디가 읽어주는 첫 그림책" → 정체성(키디 묻고→아이 답하고→부모 뭉클)에 그대로 연결.

### ⚠️ 라이선스 준수 필수 (부록 A 체크리스트)
- **크레딧 5요소** 전부: 원저자·일러스트레이터·번역가·Pratham Books·후원자
- CC-BY-SA 책은 **개작 시** 파생물도 같은 라이선스 공개 / 개작하면 "변경함" 표시
- **"Read Along" 낭독 영상은 CC-BY-NC-ND(상업 불가)** — 우리는 책 본문+삽화(CC-BY)만 사용, 낭독은 키디가

### 보조·후속 소스
- **Book Dash** (CC-BY 4.0, 그림책 200+, 판매까지 허용) — 보조 그림책
- **LibriVox** (퍼블릭도메인 오디오북 + 무인증 API) — "자기 전 오디오" 축 (미국기준 PD → 국내 저작권 재확인)
- **국립어린이청소년도서관·Open Library** — 본문 아님(서지 메타데이터), 사서추천 = 큐레이션 신뢰 시드
- 국내 상용 동요·그림책 = 제휴(티어②) / 동요는 오픈소스 빈약 → 자체 제작 검토

## 6. 심사위원 어필 요약 (3줄)

1. **발전가능성 = 방어 가능한 해자.** 검수는 복제 가능하지만, 아이와 키디의 시간·기록·관계는 복제 불가능.
2. **철학이 기능으로 증명된다.** '키디 졸업'은 리텐션을 구걸하지 않는 유일한 아동 앱임을 한 방에 보여준다.
3. **확장 경로가 이미 구체적이다.** 콘텐츠(StoryWeaver 989권, 라이선스 확인 완료)·수익(앨범 BM)·시간(타임캡슐) 모두 착수 스펙까지 준비됨.

## 부록 A. StoryWeaver 라이선스 실무 체크리스트

- [ ] 실제 넣을 책들만 **개별 라이선스 확인** (CC-BY vs CC-BY-SA vs CC0) — 989권 전수 아님
- [ ] 각 책 화면에 **크레딧 5요소** 블록 표기(원저자·일러스트·번역가·Pratham Books·후원자)
- [ ] CC-BY-SA 책을 개작하면 파생물도 동일 라이선스로 공개
- [ ] 원본 수정 시 "변경함" 명시 / "Read Along" 낭독물은 사용 안 함(NC-ND)
- [ ] Pratham Books가 KidSafe를 보증하는 인상 주지 않기(상표)
- [ ] 상업 런칭 전 최종 법률 확인 (본 문서는 라이선스 문구 해석이며 법적 자문 아님)
