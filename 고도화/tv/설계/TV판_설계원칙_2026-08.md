## 1. 정체성 — "폰이 컨트롤러, TV가 액자"

TV는 **입력 기기가 아니라 거실의 액자**다. 아이의 창작(낙서·이어그리기·자유 음성)은 폰/태블릿에서 하고, TV는 그 결과물을 온 가족이 함께 보는 큰 화면이다.

- 근거: 리모컨으로 그림 불가, 플랫폼이 외부 앱에 마이크 원시 오디오 미제공(OS 전사 텍스트만), 4~6세 음성인식 오류율 최대 35%(성인의 약 7배).
- 아이들나라(콘텐츠 창고형)가 유통·자본을 다 갖고도 실패한 반면, 우리는 "아이가 만든 것이 쌓이는 곳" — TV에 띄울 대체 불가 콘텐츠가 있다는 것이 차별화 가설.

## 2. 기능 생사표

| 기능 | TV에서 | 비고 |
|---|---|---|
| 안전 검수 영상 시청 | ✅ **최적** | TV는 영상 재생 전용 하드웨어 — 폰보다 낫다 |
| 가족 책장(그림일기 열람) | ✅ 핵심 용도 | 썸네일 그리드 + 한 장 크게 보기 |
| 음성 편지 **재생**(듣기) | ✅ 가능 | 죽는 건 녹음(입력)이지 재생이 아니다 |
| **인터뷰형 그림일기** | ✅ 가능 (오너 확정) | 키디가 묻고 → 아이가 **선택지**로 답 → AI가 그림 생성 → TV 표시. TV에서 성립하는 유일한 상호작용 = 리모컨 선택 |
| 데일리 체크인(선택지형) | ✅ 가능 | 감정 이모지 고르기 = 선택지 입력 |
| 낙서·이어그리기 | ❌ 폰/태블릿 전용 | 리모컨으로 그리기 불가 |
| 음성 녹음·자유 발화 | ❌ 배제 | 마이크 원시 오디오 미제공 + 아동 인식률. 예외: KT 지니 음성이 계약으로 열리면 재검토(질문 A6-보) |
| 텍스트 입력 | ❌ 배제 | 리모컨 자판은 아동 불가 |
| 결제 | ❌ TV에 결제 UI 0 | 웹/앱에서 팔고 TV는 로그인만(업계 표준+애플·구글 정책 정합). KT 합산청구가 열리면 재검토(질문 B1) |

## 3. 극단적 경량화 5원칙

셋톱 실측: 기가지니3 = Android TV 11 / **RAM 3GB / 저장 8GB**. "화면은 제일 큰데 두뇌는 보급형 폰"이 전제.

1. **이미지는 썸네일만.** 책장 그리드에 원본 금지 — 2단 보관 원칙(열람용 썸네일/인쇄용 원본) 재사용. base64 4.83MB 스크롤 사고의 교훈.
2. **애니메이션 절제.** 키디 포즈 전환·팝업 애니메이션은 TV에서 끊김의 원흉. 정지 이미지 + 최소 페이드만.
3. **보이는 것만 그리기.** 긴 목록(그림일기 100장)은 화면에 보이는 6~8장만 렌더.
4. **장시간 켜둠 시험 필수.** TV 앱은 몇 시간씩 켜져 있다 — 메모리 누수는 폰에서 안 보여도 TV에서 죽는다.
5. **화면 요소 최소화.** 램 절약 + 리모컨 4회 이내 도달(LG 심사 기준 계보) + 10-foot 가독성(멀리서 크게)을 한 번에.

## 5. 진출 경로 — KT 셋톱 웹뷰 시나리오

- 일반 스마트TV(삼성 Tizen·LG webOS) 네이티브 진출: **배제** (삼성=한국 출시 불가 벽, LG=업데이트마다 재심사, 엔진 절벽 — 조사 1·2축).
- 유일한 현실 경로: **KT 스카이라이프/지니TV 셋톱 + 웹뷰 방식.** 웹뷰는 운영 문제(용량·재심사·배포)를 풀고, 물리 문제(성능·엔진·입력)는 액자 전략으로 우회.
- 승부질문 3연타: **A2(웹뷰 가능?) → A3(엔진 버전?) → A5(YouTube 재생?)** — 상세는 `../KT연동/KT스카이라이프_질문리스트.md`.
- Android TV의 숨은 이점: 웹뷰 엔진이 플레이스토어로 업데이트 가능한 구조(삼성·LG의 '엔진 절벽'과 다름) — 셋톱 실제 동작은 KT 확인 필요.

## 6. 선행 조건 (모든 길이 여기로)

**그림일기 서버 이전.** TV에 띄울 데이터가 서버에 있어야 액자가 성립한다. 로컬(IndexedDB) 저장 구조로는 TV 시나리오 자체가 불가능. (서버 이전은 2026-08-02 오너 확정, 사전조사 게이트 대기 — `questions/미해결_질문_현황.md` 🔴 1~3.)

## 7. 음성·개인정보 원칙 (TV 맥락)

- **음성 2종 원칙**: 입력용(즉시 글자화·미저장·성문 추출 없음) / 간직용(부모 명시 선택 저장). "키디는 아이 목소리를 남기지 않습니다."
- 성문(생체인식정보) 추출은 하지 않는다 — 정책·계약서에 명문화 (한국 기준: 원본 음성=일반 개인정보, 성문 추출 시에만 민감정보급).
- KT 지니 음성이 열릴 경우 유리한 계약 구조 = KT가 독립 처리자(자기 약관 수집), 우리는 텍스트 수령자. '단순 경유' 면제는 한국법에 없음. 상세: KT 질문리스트 D3.
