# 💡 아이디어 서랍

> **이 문서는 무엇인가**
> 팀장이 세션마다 던지는 **키디 신기능 아이디어**가 쌓이는 곳. 채택 여부와 무관하게 **전부 남긴다** — 지금은 별로여도 나중에 다른 조각과 붙어 살아날 수 있다.
> 목적은 채택이 아니라 **오너의 발상 촉매**. (오너 요청, 2026-08-04)

## 흐름

```
팀장이 던짐 → 이 서랍에 기록 → 오너가 낙점 → README 체크리스트로 승격 → 브리프(GD-n)
```

## 아이디어를 던질 때의 재료 (팀장용 메모)

- **정체성:** 아이의 첫 미디어 경험 공간 / 키디는 아이의 **비밀 친구**
- **기기:** 폰·태블릿이 주력, TV는 '액자'(입력 아님) — [tv/설계](../tv/설계/TV판_설계원칙_2026-08.md)
- **보유 기능:** 안전검수 영상추천(Tier0~2) · 데일리 체크인 · 그림일기(이어그리기·음성) · 음성편지(부모↔아이) · 주간 부모 리포트(AI 코치) · 뱃지 · 아바타 · 스케줄
- **윤리선:** 아동 대상 광고 ❌ / 의무·보상 압박 ❌ / 확률형 ❌ / 부모에게 원본 대화 노출 ❌
