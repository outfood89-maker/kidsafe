## 오너 지시 (2026-08-07)

> *"결제 플랜 화면은 맨 처음에 나오게 하는 게 맞다고 봐. 그리고 사람들이 쉽게 클릭할 수 있게 노출하는 것도 맞고.
> '결제 시 클라우드에 저장됩니다' → 이렇게 말고, **클라우드 저장 기능을 유료 플랜의 주요 기능으로 소개**하는 게 맞다는 거야."*

**이 프레이밍 전환이 핵심이다.** 같은 사실을 어떻게 말하느냐가 아니라, **무엇으로 취급하느냐**가 다르다.

| | 면책 문구로 쓸 때 | **기능으로 팔 때** |
|---|---|---|
| 사용자가 읽는 것 | *"뭔가 불리한 게 있구나"* | *"이거 좋은데?"* |
| 동의의 성격 | 형식적 절차 (읽지 않고 체크) | **자기가 원해서 켠 것** |
| 화면의 톤 | 방어적 | 자신 있음 |

⇒ **기능으로 팔면 동의 문제도 같이 풀린다.** 별도 동의 단계가 법적 관문이 아니라
*"엄마 폰에서도 보이게 할까요?"* 라는 **기능 켜기**로 읽힌다.

## 1. 이름 — 「클라우드 저장」이라고 부르지 않는다

부모에게 *"클라우드 저장"* 은 아무 감흥이 없다. 기술 용어이고, 이미 아이폰·구글에 다 있다.
**우리가 파는 건 저장이 아니라 연결이다** (`GD-8/왜_서버여야_하는가.md` — 서버는 백업이 아니라 연결).

| 후보 | 판정 |
|---|---|
| ~~클라우드 저장~~ | ❌ 기술 용어. 무엇이 좋아지는지 안 보인다 |
| ~~무제한 백업~~ | ❌ 방어적. "잃을까 봐 산다"는 프레임 |
| **가족 책장 (어디서나)** | ✅ **추천** — 이미 앱 안에 있는 이름(`FamilyShelf`)이라 학습 비용 0 |

### 추천 문구

> **📖 어디서나 열리는 가족 책장**
> 아이가 태블릿에 쓴 그림일기를, **엄마 폰에서도 아빠 폰에서도** 그대로 봅니다.
> 기기를 바꿔도 따라옵니다.

**한 줄 요약(카드용)**: *"아이 일기를 내 폰에서."*

⚠️ 🔴 **쓰면 안 되는 문구**: *"무료로도 안전하게 보관됩니다"* 류.
말하지 않는 것과 사실이 아닌 말을 하는 것은 다르다 (DECISIONS 2026-08-07 세션 6).

## 2. 플랜 구성 (가격 미정)

| | 무료 | **유료** |
|---|---|---|
| 영상 검수·안전도 | ✅ 넉넉히 | ✅ |
| 키디 대화·체크인·케어 신호 | ✅ **영원히 무료** (계획서 v2 §126) | ✅ |
| 그림일기 쓰기·보기 | ✅ | ✅ |
| **📖 어디서나 열리는 가족 책장** | ❌ | ✅ **주요 기능** |
| 가족 앨범 PDF·실물 인쇄 | ❌ | ✅ (프리미엄 1순위 — 서버 저장이 전제) |
| 키디 문집 | ❌ | ✅ |
| AI 정밀검수 무제한 | ❌ (하루 20회) | ✅ |

> **안전·정서 기본 기능은 영원히 무료** — 계획서 v2 의 원칙. 유료화가 이 선을 넘지 않는다.
> 파는 것은 **연결과 형태**(다른 기기·종이·책)지, **아이의 안전**이 아니다.

## 3. 노출 지점 — "맨 처음" 을 어디로 볼 것인가

오너 지시는 **① 맨 처음 노출 ② 쉽게 클릭** 둘이다. 아래처럼 나눠 잡는다.

### ㉠ 상시 노출 (= 쉽게 클릭)

| 위치 | 형태 |
|---|---|
| 랜딩 상단 내비 | "요금제" — **로그인 전에도** 보인다 |
| 랜딩 푸터 | 처리방침 옆 |
| 내 계정 → 멤버십 탭 | 이미 탭이 있다 |
| 부모 대시보드 | 잠긴 기능 옆 자물쇠 → 탭하면 요금제 |

### ㉡ 온보딩 첫 노출

**프로필 만들기 직후 1회.** 아직 아이가 안 써봤어도 *무엇을 살 수 있는지*는 본다.
→ 반드시 **건너뛰기**가 있어야 한다(닫을 수 없는 결제 화면은 스토어 심사에서도 걸린다).

### ㉢ 🔴 진짜 전환이 일어나는 지점 — **첫 그림일기를 간직한 직후**

> *"이 일기, 엄마 폰에서도 보시겠어요?"*

여기가 가장 잘 팔린다. **방금 만든 것이 눈앞에 있고, 그게 이 기기에만 있다는 걸 그 순간 이해하기 때문이다.**
요금제 페이지에서 추상적으로 설명하는 것보다 훨씬 강하다.

⚠️ 팀장 의견: ㉡보다 ㉢이 중요하다. ㉡만 하면 "가입하자마자 돈 내라"로 읽혀 이탈이 크다.
**둘 다 하되 기대는 ㉢에 건다.**

## 4. 🔴 결제와 동의는 분리한다 (변경 불가)

```
요금제 화면            결제               기능 해금            별도 동의
"어디서나 열리는   →   결제 완료    →    가족 책장 켜기   →   "그림일기를 서버에
 가족 책장"                              버튼 나타남           보관하는 데 동의"
   (기능 소개)                                                  (여기서 처음)
```

- 결제 화면에 *"결제 시 클라우드에 저장됩니다"* 를 넣어 동의를 갈음하지 **않는다.**
- 요금제 화면의 기능 소개는 **광고이지 동의가 아니다.** 동의는 기능을 켜는 시점에 따로 받는다.
- 근거: 법 제22조·제28조의8 / 전문가 질문 `B1 초안` 부록 A #21-1
