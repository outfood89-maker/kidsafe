# 유료 플랜 — 구성 · 이름 · 노출 지점

작성: 2026-08-07 · 결정 근거: `DECISIONS.md` 2026-08-07 세션 6
⚠️ **가격은 이 문서에 없다.** 오너 지시로 가격 산정은 뒤로 미뤘다(`README.md` §4 재개 조건 2·3 미충족).
이 문서는 **가격이 정해지면 그대로 쓸 수 있는 것들** — 무엇을 팔고, 뭐라 부르고, 어디서 보여줄지다.

## 오너 지시 (2026-08-07)

> *"결제 플랜 화면은 맨 처음에 나오게 하는 게 맞다고 봐. 그리고 사람들이 쉽게 클릭할 수 있게 노출하는 것도 맞고.
> '결제 시 클라우드에 저장됩니다' → 이렇게 말고, **클라우드 저장 기능을 유료 플랜의 주요 기능으로 소개**하는 게 맞다는 거야."*

**이 프레이밍 전환이 핵심이다.** 같은 사실을 어떻게 말하느냐가 아니라, **무엇으로 취급하느냐**가 다르다.

| | 면책 문구로 쓸 때 | **기능으로 팔 때** |
|---|---|---|
| 사용자가 읽는 것 | *"뭔가 불리한 게 있구나"* | *"이거 좋은데?"* |
| 동의의 성격 | 형식적 절차 (읽지 않고 체크) | **자기가 원해서 켠 것** |
| 화면의 톤 | 방어적 | 자신 있음 |

⇒ **기능으로 팔면 동의 문제도 같이 풀린다.** 별도 동의 단계가 법적 관문이 아니라
*"엄마 폰에서도 보이게 할까요?"* 라는 **기능 켜기**로 읽힌다.

## 1. 이름 — 「클라우드 저장」이라고 부르지 않는다

부모에게 *"클라우드 저장"* 은 아무 감흥이 없다. 기술 용어이고, 이미 아이폰·구글에 다 있다.
**우리가 파는 건 저장이 아니라 연결이다** (`GD-8/왜_서버여야_하는가.md` — 서버는 백업이 아니라 연결).

| 후보 | 판정 |
|---|---|
| ~~클라우드 저장~~ | ❌ 기술 용어. 무엇이 좋아지는지 안 보인다 |
| ~~무제한 백업~~ | ❌ 방어적. "잃을까 봐 산다"는 프레임 |
| **가족 책장 (어디서나)** | ✅ **추천** — 이미 앱 안에 있는 이름(`FamilyShelf`)이라 학습 비용 0 |

### 추천 문구

> **📖 어디서나 열리는 가족 책장**
> 아이가 태블릿에 쓴 그림일기를, **엄마 폰에서도 아빠 폰에서도** 그대로 봅니다.
> 기기를 바꿔도 따라옵니다.

**한 줄 요약(카드용)**: *"아이 일기를 내 폰에서."*

⚠️ 🔴 **쓰면 안 되는 문구**: *"무료로도 안전하게 보관됩니다"* 류.
말하지 않는 것과 사실이 아닌 말을 하는 것은 다르다 (DECISIONS 2026-08-07 세션 6).

## 2. 플랜 구성 (가격 미정)

| | 무료 | **유료** |
|---|---|---|
| 영상 검수·안전도 | ✅ 넉넉히 | ✅ |
| 키디 대화·체크인·케어 신호 | ✅ **영원히 무료** (계획서 v2 §126) | ✅ |
| **그림일기 — AI 그림 만들기 · 이어 그리기** | ⏳ **체험 7일** | ✅ |
| 그림일기 — 손으로 그리기 · 글 쓰기 | ✅ | ✅ |
| 그림일기 — **이미 쓴 것 보기** | ✅ | ✅ |
| **📖 어디서나 열리는 가족 책장** | ❌ | ✅ **주요 기능** |
| 가족 앨범 PDF·실물 인쇄 | ❌ | ✅ (프리미엄 1순위 — 서버 저장이 전제) |
| 키디 문집 | ❌ | ✅ |
| AI 정밀검수 무제한 | ❌ (하루 20회) | ✅ |

> **안전·정서 기본 기능은 영원히 무료** — 계획서 v2 §126 의 원칙. 유료화가 이 선을 넘지 않는다.
> 파는 것은 **연결과 형태**(다른 기기·종이·책)지, **아이의 안전**이 아니다.
> ✅ 확인: 그 원칙의 목록은 **케어 신호·체크인·온기 서랍** 셋이며 **그림일기는 포함되지 않는다.**
> 따라서 그림일기 유료화는 원칙 위반이 아니다. (초판에서 그림일기를 무료로 적은 것은 팀장 임의였다)

---

### 🔍 그림일기 — 왜 '쓰기'와 '보기'를 갈랐나 (2026-08-07 원가 체크)

> 오너 지시: *"그림일기 쓰기와 보기는 유료 체험 7일 동안만 가능하게 하고 그 이후로는 유료 아니면 못 쓰게 하는 게 맞다. **수지타산에 안 맞거든.** 이것도 체크 좀."*

**체크 결과 — 유료화 판단은 맞다. 다만 원가가 있는 곳은 '쓰기' 중에서도 AI 그림 하나다.**

| 그림일기 동작 | 1회 원가 | 근거 |
|---|---|---|
| **AI 그림 만들기** | **~40원** | `README.md` §1 (⚠️ **미실측 추정**) |
| **이어 그리기** | **~90원** | 동일 (⚠️ 미실측 추정) |
| 손으로 직접 그리기 · 글 쓰기 | **0원** | 외부 API 호출 없음 |
| **이미 쓴 일기 보기** | **0원** | 무료 사용자는 **로컬 저장**이라 서버를 쓰지 않는다 |

**월 추정(아이 1명, 주 3회 가정): 480~1,080원. 무료 무제한으로 둘 기능이 아니다.**

#### ⚠️ 비교 정정 (2026-08-07, 오너 지적으로 발견)

초판에서 *"키디 대화(월 940원)와 맞먹는다"* 고 적었는데 **최악값끼리 비교한 것이었다.**

`measure_all_llm.py:102` 가 스스로 적어놨다 — *"출력은 max_tokens 상한이라 실제보다 크게 잡힌 값(**실응답은 보통 그 절반 이하**)"*.
게다가 `chat.py` 의 `max_tokens` 는 **수준별**(초급 150 / 중급 260 / 고급 700)인데 `README` 의 6.27원은 **고급 700 기준**이다.

| 대화 수준 | 입력(1,046 토큰) | 출력 상한 | 1회 |
|---|---|---|---|
| 초급 | 1.44원 | 150 → 1.04원 | **2.48원** |
| 중급 | 1.44원 | 260 → 1.79원 | **3.24원** |
| 고급 | 1.44원 | 700 → 4.83원 | 6.27원 ← README 값 |

여기에 "실응답은 절반 이하"를 적용하면 초급 아이는 **회당 약 2원**, **월 200~300원** 선이다.

**⇒ 그림일기(480~1,080원)는 대화보다 2~4배 비싸다. 유료화 판단이 오히려 더 강해진다.**

> 🔴 배운 것: **`README` 의 LLM 단가표는 전부 최악 가정이다.**
> 기능 간 비교나 손익 판단에 그대로 쓰면 안 된다. 특히 `max_tokens` 가 수준별로 갈리는 경로는
> 어느 수준으로 잰 값인지 확인할 것.

#### 🔴 그런데 '보기'를 잠그면 아끼는 돈이 **0원**이다

무료 사용자의 그림일기는 **그 기기 안에** 있다. 서버 비용이 발생하지 않는다.
보기를 잠가도 절감이 없고, 대신 두 가지를 얻는다:

1. **"아이가 만든 걸 인질로 잡는다"는 프레임.** 심지어 데이터는 사용자 기기에 있는데 앱이 안 보여주는 모양새다.
2. **열람권(법 제35조) 확인 필요.** 요금 미납을 이유로 개인정보 열람을 막을 수 있는지 확실하지 않다.

⇒ **비싼 곳만 잠근다.** 원가는 전부 잡히고 인질 프레임은 피한다.
그리고 전환에도 더 낫다 — 아이가 *"그림 만들래"* 하는 순간이 가장 강한 전환 지점인데,
바로 그때 요금제가 뜬다(§3-㉢과 같은 원리).

#### ✅ 그림 압축 실측 (2026-08-07, 실기기 브라우저)

저장·업로드 직전에 **해상도는 유지하고 포맷만** 무손실 PNG → WebP q0.9 로 바꾼다.

| 대상 | 원본 | 압축 후 | |
|---|---|---|---|
| **AI 그림 1장** | **3.82MB** | **0.68MB** | 🎯 **82% 감소** |
| 이미 작은 그림(0.40MB) | 0.40MB | 0.40MB | 무개입(임계 600KB) |
| 낙서(0.06MB) | 0.06MB | 0.06MB | 무개입 |
| 기기 전체 3장 합계 | 4.27MB | 1.13MB | 74% 감소 |

**스토리지 원가가 약 5.6배 저렴해진다.** 아이 1명이 주 3회 그림일기를 쓰면 연 144장 —
압축 전 **550MB/년** 이 압축 후 **98MB/년** 이 된다.

⚠️ 해상도(1536×1024)는 그대로다. 프리미엄 1순위가 **앨범 실물 인쇄**라 가로세로를 줄이면 되돌릴 수 없다.
⚠️ 스토리지 **단가**는 아직 안 넣었다 — `README.md` §3 가격 시뮬은 인프라 비용 제외 값이다.

#### ⚠️ 판단의 근거가 아직 추정이다

**그림 단가 40원/90원은 `미실측(추정)`이다.** 이 숫자 위에 유료화 결정을 올리고 있으므로,
가격 재개 전에 **실측이 필요하다.** (`measure_all_llm.py`·`measure_deep_cost.py` 는 있으나 이미지 생성 측정 도구는 없다)

## 3. 노출 지점 — "맨 처음" 을 어디로 볼 것인가

오너 지시는 **① 맨 처음 노출 ② 쉽게 클릭** 둘이다. 아래처럼 나눠 잡는다.

### ㉠ 상시 노출 (= 쉽게 클릭)

| 위치 | 형태 |
|---|---|
| 랜딩 상단 내비 | "요금제" — **로그인 전에도** 보인다 |
| 랜딩 푸터 | 처리방침 옆 |
| 내 계정 → 멤버십 탭 | 이미 탭이 있다 |
| 부모 대시보드 | 잠긴 기능 옆 자물쇠 → 탭하면 요금제 |

### ㉡ 온보딩 첫 노출

**프로필 만들기 직후 1회.** 아직 아이가 안 써봤어도 *무엇을 살 수 있는지*는 본다.
→ 반드시 **건너뛰기**가 있어야 한다(닫을 수 없는 결제 화면은 스토어 심사에서도 걸린다).

### ㉢ 🔴 진짜 전환이 일어나는 지점 — **첫 그림일기를 간직한 직후**

> *"이 일기, 엄마 폰에서도 보시겠어요?"*

여기가 가장 잘 팔린다. **방금 만든 것이 눈앞에 있고, 그게 이 기기에만 있다는 걸 그 순간 이해하기 때문이다.**
요금제 페이지에서 추상적으로 설명하는 것보다 훨씬 강하다.

⚠️ 팀장 의견: ㉡보다 ㉢이 중요하다. ㉡만 하면 "가입하자마자 돈 내라"로 읽혀 이탈이 크다.
**둘 다 하되 기대는 ㉢에 건다.**

## 4. 🔴 결제와 동의는 분리한다 (변경 불가)

```
요금제 화면            결제               기능 해금            별도 동의
"어디서나 열리는   →   결제 완료    →    가족 책장 켜기   →   "그림일기를 서버에
 가족 책장"                              버튼 나타남           보관하는 데 동의"
   (기능 소개)                                                  (여기서 처음)
```

- 결제 화면에 *"결제 시 클라우드에 저장됩니다"* 를 넣어 동의를 갈음하지 **않는다.**
- 요금제 화면의 기능 소개는 **광고이지 동의가 아니다.** 동의는 기능을 켜는 시점에 따로 받는다.
- 근거: 법 제22조·제28조의8 / 전문가 질문 `B1 초안` 부록 A #21-1
