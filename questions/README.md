# 📂 questions — 해결해야 할 문제·질문 보관소

> **이 폴더는 무엇인가**
> 지금 당장 답할 수 없지만 **나중에 반드시 꺼내 써야 하는 질문·미해결 문제**를 모아두는 곳이다.
> 짝꿍 폴더 = `research/` (모아둔 **자료**는 저기, 풀어야 할 **질문**은 여기).

## 사용법

- 외부 미팅(KT 등) 전 → 해당 질문 리스트를 꺼내 들고 간다.
- 답을 얻으면 → 질문 옆에 **답 + 날짜**를 적는다. 질문을 지우지 않는다(무엇을 몰랐었는지도 자산).
- 새 미해결 문제가 생기면 → `미해결_질문_현황.md`에 한 줄 추가.
