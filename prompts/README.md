# 🧭 역할 프롬프트 (4인 체제)

KidSafe/Kiddy 프로젝트를 **Claude Code 창 3개**로 나눠 돌리기 위한 시스템 프롬프트 모음.

## 구조

```
오너(Freddie)  ← 모든 결정·중계·배포·SQL·실기기 테스트
 ├─ 팀장 (창1)          전략·우선순위·아동 카피 게이트·검수·문서화   (코드 안 짬)
 ├─ 컨트롤타워 (창2)    설계·브리프 발부·diff 리뷰·커밋
 └─ 작업자 (창3)        구현 → diff 보고 (커밋 보류)
```

**창끼리는 서로를 모른다.** 모든 소통은 오너가 복사-붙여넣기로 중계한다.
→ 각 창의 산출물은 **그 자체로 복사 가능한 완결 블록**이어야 한다.

## 일 흐름

```
팀장: 방향·우선순위 결정  →  [팀장 → 컨트롤타워] 블록
   → 컨트롤타워: 설계 → [브리프] 발부
      → 작업자: 구현 → [작업자 → 컨트롤타워] diff 보고 (커밋 X)
         → 컨트롤타워: 리뷰 → 커밋
            → 팀장: 검수·카피 스탬프 → 다음 사이클
```

## 파일

| # | 파일 | 붙여넣을 창 |
|---|---|---|
| 1 | `1_팀장_시스템프롬프트.md` | 팀장 창 |
| 2 | `2_컨트롤타워_시스템프롬프트.md` | 컨트롤타워 창 |
| 3 | `3_작업자_시스템프롬프트.md` | 작업자 창 |

## 창 여는 법 (VS Code)

명령 팔레트(`Cmd + Shift + P`) → `Claude Code: Open in New Tab` (단축키 `Cmd + Shift + Esc`)
탭을 화면 옆으로 드래그하면 나란히 놓고 볼 수 있다.

⚠️ 세 창이 **같은 폴더**를 본다. 서로가 뭘 하는지 모르므로 **실제 파일 수정은 작업자 창에서만** 한다.
팀장·컨트롤타워 창은 읽기·설계·리뷰만.

## 핵심 규칙 (3개 문서 공통)

- **아이 먼저.** "아이의 하루가 가족에게 닿는가 / 아이에게 정직한가"에 지면 버린다.
- **아동 노출 문구는 팀장 스탬프 전용.** 컨트롤타워·작업자가 지어내지 않는다.
- **작업자는 커밋하지 않는다.** `git add .` 금지, 지정 파일만 스테이징.
- **기존 코드 삭제 금지** — 주석처리로 비활성화(복구 가능하게).
- **사실은 코드가, 분위기만 LLM.**
